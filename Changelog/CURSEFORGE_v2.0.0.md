# Echo of the Void 2.0.0

Echo of the Void 2.0 turns the mod into a complete, progressively paced horror campaign while keeping its anomalies subtle, Minecraft-native and fair.

## Highlights

- Standard campaign rebuilt around approximately 50 Minecraft days.
- Optional extra-long 100-day mode with the same normalized story arc.
- A complete late-campaign pacing arc with an intentionally ambiguous aftermath.
- Six discoverable journals with non-sequential, time-weighted discovery.
- Rebuilt development and QA tooling.
- Expanded ambient anomalies, weather, Vanilla-derived variants and Special encounters.
- Improved Special AI, animation, audio, rewards and cleanup.
- Safer event spacing and broader anti-repetition logic.
- Dedicated-server, persistence, loot, world-mutation and compatibility fixes.

The update preserves existing 1.1.1 world data and public identifiers. Back up important worlds before updating any modded installation.

## File information

- Game version: Minecraft 1.21.1
- Mod loader: NeoForge 21.1.219 or newer in the 21.1 line
- Java: 21
- File type: Release
- Environment: Client and dedicated server
- Required dependencies: NeoForge only; no external content mod is required

Install the same `EchoOfTheVoid-2.0.0.jar` on the server and every connecting client.
